# Widad Elyamani — Aerospace Engineering Portfolio

A static portfolio of ten engineering case studies: CFD, structural FEA, composites,
design optimisation, and a full design-build-fly aircraft project.

**Live site:** https://Widad-Elyamani.github.io/portfolio/


---

## Projects

| # | Project | Discipline | Key tools |
|---|---------|-----------|-----------|
| 01 | Stiffened Wing Box Analysis & Optimization | Structural | Analytical, spreadsheet |
| 02 | CFD Analysis of NACA 0015 Airfoil | CFD (incompressible) | ANSYS Fluent, k-ω |
| 03 | Compressible Flow in Converging Nozzle (ARN2) | CFD (compressible) | ANSYS Fluent, SST k-ω, NASA validation |
| 04 | Structural Design for Steel Shed | Structural | Eurocode 3, SolidWorks |
| 05 | BMX Crank Arm — Design, FEA & Optimisation | FEA + Fatigue | Creo, ANSYS Workbench |
| 06 | Alpha Jet Composite Radome (PFE, Airbus) | Composites + Multiphysics | CATIA V5, ANSYS ACP/Fluent/Modal/Autodyn |
| 07 | 1045 Propeller Blade CFD | CFD (rotating) | ANSYS Fluent, sliding mesh |
| 08 | Automated FEA of a Cantilever Beam | Automation | ANSYS Mechanical, Python ACT API |
| 09 | Transonic CFD of the ONERA M6 Wing | CFD (transonic) | ANSYS Fluent, Spalart–Allmaras |
| 10 | PowerFly Girls Glider — Design, Build & Flight Test | Aircraft design | CATIA V5, Raymer method, fabrication |

## Structure

```
index.html                  Gallery page — entry point
project_01…10_*.html        Individual case studies
assets/                     All images (relative paths only)
404.html                    Fallback page
.nojekyll                   Tells GitHub Pages to skip Jekyll processing
```

Every page is self-contained: HTML with inline CSS, no build step, no
dependencies, no JavaScript. Open `index.html` in a browser to view locally.
